Si olvidaste tu clave: si tienes la entrada directa activada, entra con ella y cámbiala desde dentro. Si no, nadie puede recuperarla — tus datos nunca salen de este dispositivo y no hay copia de tu clave en ningún servidor —. En ese caso sí puedes eliminar el perfil sin la clave, desde «Eliminar este perfil» → «No recuerdo mi clave»: se borra todo y empiezas de cero.

Se borrarán todos los datos de este perfil guardados en este dispositivo (movimientos, documentos, recordatorios e inversiones). No se pueden recuperar.

Sin la clave también puedes borrarlo: escribe el nombre exacto del perfil y la palabra ELIMINAR. Así se confirma que lo borras tú a propósito y no por error. Borrar no enseña los datos a nadie: simplemente desaparecen de este dispositivo.

Es tu cuenta personal en este dispositivo. Tus datos se guardan solo en el navegador de este móvil u ordenador: no se suben a ningún servidor y nadie más puede verlos. La clave solo separa tu perfil de otros perfiles en este mismo aparato; si borras los datos del navegador, se pierde todo, así que descarga una copia de seguridad de vez en cuando desde dentro.
